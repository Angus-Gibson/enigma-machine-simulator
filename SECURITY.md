## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it by:
- Opening a private security advisory via GitHub's "Report a vulnerability" feature (Security tab → Advisories), or

Please do not open a public issue for security vulnerabilities.

I'll aim to acknowledge reports within 5 business days and provide an update on remediation timeline once the issue is confirmed.
